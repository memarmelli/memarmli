# معمار ملی

صفحهٔ اصلی آرشیو دانش‌آموختگان معماری دانشگاه شهید بهشتی، با پس‌زمینهٔ مشکی و طراحی تیره.

## اجرا

بدون نصب وابستگی یا مرحلهٔ ساخت:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

سپس `http://127.0.0.1:4173` را باز کنید.

## تصاویر و لوگوهای اصلی

- عکس‌های تأییدشده را در `dist/assets/` بگذارید و مسیر `image` را در `dist/cohorts.js` تغییر دهید.
- سال‌ها و تاریخ‌های فعلی **دادهٔ نمونه** هستند. `graduatedAt` تاریخ میلادی فارغ‌التحصیلی است، با قالب `YYYY-MM-DD`؛ سال ورود شمسی در `year` قرار می‌گیرد.
- ورودی با تاریخ فارغ‌التحصیلی جدیدتر بالاتر قرار می‌گیرد. فقط موارد `published: true` نمایش داده می‌شوند. برای عکس واقعی، `sample: false` را تنظیم کنید.
- لوگوهای سربرگ موقتاً با نام سازمان مشخص شده‌اند. پس از دریافت فایل اصلی، محتوای `.university` و `.artinext` در `dist/index.html` را با تصویر دارای متن جایگزین مناسب عوض کنید.
- هر کادر در همهٔ اندازه‌ها شامل **۲۰٪ عدد سال در چپ** و **۸۰٪ تصویر در راست** است. با انتخاب عکس، نسخهٔ کامل در پنجره باز می‌شود؛ Escape آن را می‌بندد.

این پروژه فقط صفحهٔ اول را پیاده‌سازی می‌کند. انتشار گروه جدید با افزودن داده و انتشار نسخهٔ جدید انجام می‌شود؛ پنل مدیریت جداگانه ندارد.
